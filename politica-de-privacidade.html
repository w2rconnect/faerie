Política de Privacidade

Extensão: W2R Connect Transferência de Dados · Última atualização: 24/07/2026

Esta extensão foi criada para agilizar o preenchimento de formulários, transferindo dados do aplicativo w2rconnect.app para o formulário de cadastro do Caixa Aqui (caixaaqui.caixa.gov.br). Esta política explica quais dados a extensão manipula e como.

Quais dados a extensão manipula

Para preencher o formulário de destino, a extensão manipula os dados de cadastro que o próprio usuário seleciona no aplicativo w2rconnect.app, que podem incluir:

  • Informações de identificação pessoal: nome, e‑mail, data de nascimento, filiação, endereço e números de documentos (CPF, RG, CNH), inclusive dados de cônjuge quando aplicável.
  • Informações financeiras: dados de renda e da fonte pagadora (por exemplo, valores de renda e CNPJ/CPF da fonte).

Como os dados são usados

  • Os dados são obtidos do aplicativo w2rconnect.app apenas quando o usuário aciona a transferência, e são usados exclusivamente para preencher automaticamente os campos do formulário de destino.
  • Os dados são armazenados somente no dispositivo do usuário, de forma temporária, usando o armazenamento local do navegador (chrome.storage.local), apenas para manter o preenchimento consistente entre os recarregamentos de página do formulário.
  • Os dados expiram automaticamente após um curto período e podem ser apagados pelo usuário a qualquer momento.

O que a extensão NÃO faz

  • Não envia os dados para servidores próprios da extensão nem para qualquer serviço externo. Os dados trafegam apenas do aplicativo de origem para o formulário de destino, no navegador do próprio usuário.
  • Não vende nem compartilha os dados com terceiros.
  • Não usa os dados para finalidades diferentes do preenchimento de formulários, nem para determinar crédito ou capacidade de empréstimo.
  • Não coleta credenciais de login, histórico de navegação, localização ou atividade do usuário.

Permissões e por quê

  • Acesso a w2rconnect.app: para exibir o aplicativo de origem no painel lateral e obter os dados que o usuário escolher transferir.
  • Acesso a caixaaqui.caixa.gov.br: para preencher automaticamente os campos do formulário de destino.
  • activeTab / scripting / tabs: para preencher a aba de formulário correta quando o usuário aciona a transferência.
  • storage: para guardar os dados temporariamente no dispositivo, conforme descrito acima.
  • sidePanel: para exibir o painel lateral com o aplicativo de origem.

Controle do usuário

O usuário controla quando os dados são transferidos (a ação é sempre iniciada por ele) e pode limpar os dados armazenados a qualquer momento pela própria extensão. A remoção da extensão apaga qualquer dado local remanescente.

Contato
